Package anatomy

What the zip is for.

A logo package is the organized set of versions, colourways, and formats so the mark stays sharp on a stamp, a screen, or a billboard. Oriel follows a client-friendly folder order: variation, then purpose, then colour, then file type.

Variations

One drawing rarely covers every placement. Supply the lockups you actually designed.

  • Primary — the main logo
  • Horizontal — headers and web nav
  • Brandmark — symbol for avatars and swag
  • Wordmark — type when the icon is too small

Colourways

Full colour is not enough. The pack always builds four treatments from each uploaded lockup.

  • Full colour on light grounds
  • Inverse — colour-reversed for dark grounds
  • Solid black for one-colour print
  • Solid white knockout for dark or photo grounds

Formats

Raster files are pixels. Vector files are paths. Both belong in the handoff, for different jobs.

  • PNG — transparency, web, social
  • JPG — flat previews, no transparency
  • SVG & PDF — placement files that scale
  • AI & EPS — only if you drop the originals

Digital and print folders

01 Digital / 02 Print

Digital holds RGB images and placement vectors: PNG, JPG, SVG, and PDF. Print holds PDF artwork plus a colour note. CMYK values are process approximations from the uploaded pixels. The Pantone folder explains spot colour and lists those approximations — it does not invent a Pantone code.

Sizes included

Longest edge at 512, 1024, and 1920, plus a 3840 master when enabled. Favicons at 16–512, Apple touch 180, Android 192/512, and plates for X, LinkedIn, YouTube, Instagram, and a 1200×630 link card. A PDF file guide sits at the root of the zip.
